# 🩻 CT Vision | Two-Input CT Scan Reconstruction

**Reconstructing medical images through computational imaging and Python.**

A collaborative project exploring CT scan reconstruction using two inputs, implemented in a Jupyter Notebook. This repository documents our implementation and workflow for experimenting with CT image reconstruction.

---

## ✨ What This Project Explores

- **Two-input reconstruction:** Working with two inputs in the reconstruction workflow.
- **Image processing:** Exploring computational techniques for CT image reconstruction.
- **Visual analysis:** Using Python notebooks to inspect and visualize results.
- **Reproducible workflow:** Keeping the implementation organized and accessible through GitHub.

## 🧠 Project Workflow

`Input 1` + `Input 2` → `Reconstruction Process` → `Output Image`

*Conceptual workflow; the exact processing steps depend on the notebook implementation.*

## 🚀 Getting Started

### Requirements
- Python 3.x
- Jupyter Notebook
- Python libraries required by the notebook

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/CT-Scan-Reconstruction.git
   ```

2. Enter the project folder:

   ```bash
   cd CT-Scan-Reconstruction
   ```

3. Launch Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

4. Open `CT_Scan_Reconstructor_Two_Inputs.ipynb` and execute the cells in sequence.
